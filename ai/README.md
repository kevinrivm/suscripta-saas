# AI Control Center

This directory provides the context, structure, and guidance required for AI agents to understand and work effectively within the project.

## Important

This directory is NOT the active runtime configuration.

Active configuration sources:
- Rules → `~/.gemini/GEMINI.md`
- Workflows → `~/.gemini/antigravity/global_workflows/`
- Skills → `.agents/`

This directory serves as:
- project context
- onboarding layer
- operational documentation
- portable reference across tools and runtimes

If there is any conflict, the active runtime configuration takes precedence.

---

## Structure

- **`AI_CONTEXT.md`** → current state, decisions, and roadmap
- **`ENTRYPOINTS.md`** → technical map of the project
- **`rules/`** → portable rule definitions
- **`workflows/`** → portable workflow definitions
- **`skills/`** → portable skill definitions

---

## Usage

1. Read `AI_CONTEXT.md`
2. Read `ENTRYPOINTS.md`
3. Consult runtime configuration if needed
